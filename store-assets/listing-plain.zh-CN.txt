Typing_Practice

【简短描述】
阶段式打字学习：指法教程、严格/自由模式、速度测试、反应训练、成绩统计与 AI 素材生成。

【详细描述】
从零开始，把打字练成肌肉记忆。

Typing_Practice 是一款阶段式打字学习软件：从认识键盘、指法分工，到上排/下排键、常用单词与整段文章，循序渐进地练。

主要功能
• 阶段式课程：按「认识键盘 → 指法分工 → 上/中/下排键 → 综合」逐节进阶，每节有星级评价。
• 指法提示：屏幕键盘实时高亮下一个该按的键，练指法不靠猜。
• 严格 / 自由模式：严格模式按错就拦，自由模式可继续并支持退格纠正，随时切换。
• 速度测试：30 秒 / 1 / 2 / 5 分钟，文章或词库，实时显示 WPM、CPM 与准确率。
• 反应训练：屏幕出现单个字符，尽快按下；三档难度、S/A/B/C/D 评级与分难度最佳记录。
• 素材练习：内置文章与词库，支持导入自己的 txt，也能从在线来源取词、用 AI 生成短文或词库（填你自己的 API Key）。
• 多会话并行：最多同时保留 6 个练习，切页不丢进度，侧栏一键切换。
• 成绩统计：WPM 趋势、最近记录、课程星级、反应训练成绩一目了然。
• 本地优先：练习数据只存在本机，无需注册登录；卸载即清除。

适合谁
想从零学盲打的初学者、想提升英文录入速度的学生与办公人群、给孩子练指法的家长。

说明
• 在线素材与 AI 生成需要联网；AI 功能需自备兼容 OpenAI 接口的 API Key。
• 本应用不收集你的身份信息，详见隐私策略。
