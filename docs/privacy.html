中文

TypingPractice（下称“本应用”）是一款本地优先的打字练习软件。本政策说明本应用如何处理信息。

  1. 我们不收集、不上传你的个人身份信息；本应用无需注册或登录。
  2. 数据仅存储在本机：练习进度、历史记录、自定义素材与设置保存在你设备的本地应用数据目录。若你使用「AI 素材生成」，你填写的 API 地址、模型名与 API Key 仅保存在本机；API Key 使用操作系统提供的加密能力（Windows DPAPI）加密存储，不会发送给本应用开发者。
  3. 网络请求：
    • 在线素材——当你主动搜索时，本应用会向第三方公共接口（如 Datamuse、Tatoeba 及公开词表）发送搜索关键词，该类请求受相应第三方的隐私政策约束。
    • AI 生成——使用该功能时，本应用会把你的提示词发送到你自行配置的 AI 服务地址，并使用你自己的 API Key；该数据由你选择的服务提供商处理。
    • 检查更新（仅非商店版本）——本应用会访问 GitHub Releases 获取版本信息。
  4. 我们不使用分析或遥测，不投放广告，不出售或共享你的数据。
  5. 本应用不面向 13 岁以下儿童。
  6. 你可以随时删除本机数据：卸载本应用或清除其数据目录即可。
  7. 联系方式：GitHub Issues。

English

TypingPractice (“the App”) is a local-first typing practice application. This policy explains how the App handles information.

  1. We do not collect or upload personally identifiable information. No account or sign-in is required.
  2. Data is stored only on your device: practice progress, history, custom materials and settings are kept in the local application data folder. If you use “AI material generation”, the API endpoint, model and API key you enter are stored locally only; the API key is encrypted with an OS-provided facility (Windows DPAPI) and is never sent to the developer.
  3. Network requests:
    • Online materials — when you search, the App sends your query to third-party public APIs (e.g., Datamuse, Tatoeba, public word lists), subject to those parties’ privacy policies.
    • AI generation — your prompt is sent to the AI endpoint you configure, using your own API key, and is processed by the provider you choose.
    • Update check (non-Store builds only) — the App contacts GitHub Releases for version information.
  4. We do not use analytics or telemetry, do not show ads, and do not sell or share your data.
  5. The App is not directed to children under 13.
  6. You can delete local data at any time by uninstalling the App or clearing its data folder.
  7. Contact: GitHub Issues.
